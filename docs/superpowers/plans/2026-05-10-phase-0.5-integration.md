# Phase 0.5: Real WebRTC AEC3 + RNNoise integration — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Phase-0 stub AEC + NS in `AecChain` with real WebRTC AEC3 + RNNoise behind the same interface, on the host (macOS), driven by the existing offline (`ecnr_bench`) and live (`ecnr_live`) harnesses. After this plan, the cumulative-ERLE assertion in the smoke test rises from > 5 dB (stub) to > 15 dB (real AEC).

**Architecture:** Hybrid linear-AEC + neural-post per [ADR-0001](../../adr/0001-hybrid-aec-architecture-review.md). WebRTC AEC3 (Meson-built C++ library) handles linear echo cancellation; RNNoise (a small set of C files compiled inline into our CMake build) handles noise suppression as a post-filter. SpeexDSP resampler bridges 16 kHz chain rate to RNNoise's 48 kHz native rate. The `AecChain` public interface is preserved so `ecnr_bench` and `ecnr_live` are unchanged callers.

**Tech Stack:** C++17, CMake 3.20+, Meson (drives webrtc-audio-processing), libsndfile, miniaudio (already vendored), RNNoise (vendored as source), SpeexDSP resampler (system pkg-config).

## Stage 0 — Decision-locking (prerequisite, NOT code)

These three ADRs need to be drafted with user input before any code work. Each is a 1–2 paragraph decision document, not engineering effort.

### Stage 0 prerequisites

- [ ] **ADR-0003: Canonical sample rate** — answer: "Will the U300 system use the AEC stack while playing media (music, navigation prompts) through the same speakers?"
  - If yes → 32 kHz minimum (cuts off at 16 kHz; covers most musical content; 2× CPU cost vs 16 kHz on A55)
  - If no (voice-only) → 16 kHz is fine
  - Decision blocks: `kSampleRateHz` constant in `core/frame.h`, every WAV in `reference/synth/`, every CMake target's frame size.

- [ ] **ADR-0004: Mic channel count** — answer: "How many mics does the U300 cabin have, and do we process them per-channel or post-beamform?"
  - If single mic → current `Frame` shape (160 samples mono int16 @ 16 kHz) stays.
  - If multi-mic but pre-beamformed externally → still single-channel input to our chain; document the pre-beamforming contract.
  - If multi-mic with our chain doing beamforming → `Frame` becomes multi-channel; `AecChain` gains a beamformer stage *before* AEC3 (which is single-channel).
  - Decision blocks: `Frame` struct in `core/frame.h`; whether a new `src/pipeline/beamformer.h` is needed in this phase.

- [ ] **ADR-0005: Render-tap policy** — answer: "Where in the U300 audio HAL pipeline can we tap the render signal?"
  - If post-DRC/EQ/speaker-protect → ideal; AEC3 has the right reference.
  - If pre-DRC → need to either (a) measure those transfer functions and pre-compensate the reference, or (b) accept a residual-echo cap and lean on the neural post-filter.
  - Decision blocks: an integration contract in `src/hal/`, plus possibly a `src/pipeline/render_pre_emphasis.{h,cc}` if compensation needed.

**Action:** Bring these three questions to the U300 platform team. Until at least ADR-0003 is locked, Stage 1+ of this plan is *technically executable* (we'd build with current 16 kHz mono assumption and ship rework if it changes), but Stage 0 should happen first.

- [ ] **Step 2: Write `src/pipeline/aec3_adapter.cc`**

```cpp
#include "pipeline/aec3_adapter.h"

#include "modules/audio_processing/include/audio_processing.h"

#include <array>
#include <cstdint>

namespace ecnr {

Aec3Adapter::Aec3Adapter() = default;
Aec3Adapter::~Aec3Adapter() = default;

bool Aec3Adapter::Init(int sample_rate_hz) {
  webrtc::AudioProcessingBuilder builder;
  apm_ = builder.Create();
  if (!apm_) return false;

  webrtc::AudioProcessing::Config cfg;
  cfg.echo_canceller.enabled = true;
  cfg.echo_canceller.mobile_mode = false;
  cfg.noise_suppression.enabled = false;   // RNNoise handles NS
  cfg.gain_controller1.enabled = false;
  cfg.gain_controller2.enabled = false;
  cfg.high_pass_filter.enabled = true;     // cheap; helps DC + low-freq rumble
  apm_->ApplyConfig(cfg);

  sample_rate_hz_ = sample_rate_hz;
  return true;
}

void Aec3Adapter::Reset() {
  if (apm_) apm_->Initialize();
}

void Aec3Adapter::SetStreamDelayMs(int ms) {
  if (apm_) apm_->set_stream_delay_ms(ms);
}

void Aec3Adapter::ProcessRender(const Frame& render) {
  if (!apm_) return;
  webrtc::StreamConfig sc(sample_rate_hz_, 1);
  // APM expects float* per-channel; convert int16 → float [-1, 1]
  std::array<float, kFrameSamples> buf;
  for (int i = 0; i < kFrameSamples; ++i) {
    buf[i] = static_cast<float>(render.samples[i]) / 32768.0f;
  }
  const float* ptr = buf.data();
  apm_->ProcessReverseStream(&ptr, sc, sc, &ptr);
  (void)ptr;
}

void Aec3Adapter::ProcessCapture(const Frame& capture, Frame& out) {
  if (!apm_) { out = capture; return; }
  webrtc::StreamConfig sc(sample_rate_hz_, 1);
  std::array<float, kFrameSamples> in_buf, out_buf;
  for (int i = 0; i < kFrameSamples; ++i) {
    in_buf[i] = static_cast<float>(capture.samples[i]) / 32768.0f;
  }
  const float* in_ptr = in_buf.data();
  float* out_ptr = out_buf.data();
  apm_->ProcessStream(&in_ptr, sc, sc, &out_ptr);
  for (int i = 0; i < kFrameSamples; ++i) {
    const float v = out_buf[i] * 32768.0f;
    out.samples[i] = static_cast<int16_t>(
        v < -32768.0f ? -32768 : v > 32767.0f ? 32767 : v);
  }
}

Aec3Adapter::Stats Aec3Adapter::GetStats() const {
  Stats s;
  if (!apm_) return s;
  const auto apm_stats = apm_->GetStatistics();
  if (apm_stats.residual_echo_likelihood) {
    s.residual_echo_likelihood = *apm_stats.residual_echo_likelihood;
  }
  if (apm_stats.delay_ms) {
    s.estimated_delay_ms = static_cast<int>(*apm_stats.delay_ms);
  }
  s.converged = apm_stats.echo_return_loss_enhancement.has_value();
  return s;
}

}  // namespace ecnr
```

```cpp
void AecChain::ProcessCapture(const Frame& capture, Frame& out) {
  const auto t0 = std::chrono::steady_clock::now();
  const double e_in = FrameEnergy(capture);

  impl_->aec.ProcessCapture(capture, out);
  // (NS swap-in lands in Task 7; for now out passes through untouched)

  const double e_out = FrameEnergy(out);
  const auto t1 = std::chrono::steady_clock::now();
  impl_->stats.cpu_time_s +=
      std::chrono::duration<double>(t1 - t0).count();
  impl_->stats.audio_time_s +=
      static_cast<double>(kFrameDurationMs) / 1000.0;

  if (e_in > 1e-12 && e_out > 1e-12) {
    impl_->stats.erle_db = 10.0 * std::log10(e_in / e_out);
  } else {
    impl_->stats.erle_db = 0.0;
  }

  const auto a = impl_->aec.GetStats();
```

```cpp
namespace ecnr {

// RNNoise wrapper. RNNoise is hardcoded to 48 kHz / 480-sample frames; we

class RnNsAdapter {

  void Process(Frame& f);  // 16 kHz mono int16 in-place

 private:
  DenoiseState* st_ = nullptr;

  SpeexResamplerState_* down_ = nullptr;  // 48k -> 16k
};

}  // namespace ecnr
```

- [ ] **Step 2: Write `src/pipeline/rnnoise_adapter.cc`**

```cpp
#include "pipeline/rnnoise_adapter.h"

#include <rnnoise.h>
#include <speex/speex_resampler.h>

#include <array>
#include <cstdint>

namespace ecnr {

namespace {
constexpr int kRnnFrameSamples = 480;  // 48 kHz / 100 Hz
}  // namespace

RnNsAdapter::RnNsAdapter() = default;

RnNsAdapter::~RnNsAdapter() {
  if (st_) rnnoise_destroy(st_);
  if (up_) speex_resampler_destroy(up_);
  if (down_) speex_resampler_destroy(down_);
}

bool RnNsAdapter::Init() {
  st_ = rnnoise_create(nullptr);
  if (!st_) return false;
  int err = 0;
  up_ = speex_resampler_init(1, 16000, 48000, 5, &err);
  if (err != 0) return false;
  down_ = speex_resampler_init(1, 48000, 16000, 5, &err);
  if (err != 0) return false;
  return true;
}

void RnNsAdapter::Reset() {
  if (st_) {
    rnnoise_destroy(st_);
    st_ = rnnoise_create(nullptr);
  }
  if (up_) speex_resampler_reset_mem(up_);
  if (down_) speex_resampler_reset_mem(down_);
}

void RnNsAdapter::Process(Frame& f) {
  if (!st_ || !up_ || !down_) return;

  // 16k int16 → 48k float
  std::array<float, kFrameSamples> in_16k_f;
  for (int i = 0; i < kFrameSamples; ++i) {
    in_16k_f[i] = static_cast<float>(f.samples[i]);
  }
  std::array<float, kRnnFrameSamples> in_48k;
  spx_uint32_t in_len = kFrameSamples;
  spx_uint32_t out_len = kRnnFrameSamples;
  speex_resampler_process_float(up_, 0,
      in_16k_f.data(), &in_len, in_48k.data(), &out_len);

  // RNNoise expects float values scaled to int16-range (NOT [-1, 1]).
  rnnoise_process_frame(st_, in_48k.data(), in_48k.data());

  // 48k float → 16k float → int16
  std::array<float, kFrameSamples> out_16k_f;
  in_len = kRnnFrameSamples;
  out_len = kFrameSamples;
  speex_resampler_process_float(down_, 0,
      in_48k.data(), &in_len, out_16k_f.data(), &out_len);

  for (int i = 0; i < kFrameSamples; ++i) {
    const float v = out_16k_f[i];
    f.samples[i] = static_cast<int16_t>(
        v < -32768.0f ? -32768 : v > 32767.0f ? 32767 : v);
  }
}

}  // namespace ecnr
```
